Git est un système de contrôle de version décentralisé qui permet de suivre l'évolution des fichiers.
Il est utile car il permet de revenir à des versions antérieures, de travailler à plusieurs sans écraser le travail des autres, et de garder un historique clair.
Dans ce TP, nous avons appris à configurer Git dans Colab, à cloner un dépôt distant, à créer un fichier, à faire un commit et à pousser les modifications vers GitHub.
Nous avons également compris l'importance des tokens d'accès pour sécuriser les opérations.
--- Description de notre projet ---
Projet : Analyse génomique d'échantillons environnementaux.
Nous souhaitons versionner ce projet avec Git pour suivre l'évolution de nos scripts d'analyse et les résultats. Cela nous permet de travailler à 3 sur le même code et de garder un historique clair.
